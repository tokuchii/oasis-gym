# Offline Support for OASIS FITNESS GYM

## Goal
Make the Capacitor Android app (and browser) work offline — especially the staff dashboard at the gym front desk.

## Approach
Manual service worker + IndexedDB + write queue. No new npm dependencies — browser-native APIs only.

## New Files (7)

### 1. `public/manifest.json`
PWA manifest with app name, theme color `#0a0a0a`, icon from `favicon.svg`.

### 2. `public/sw.js`
Service worker:
- **Precache** app shell (`/staff`, `/favicon.svg`, Nuxt hashed assets via `/_nuxt/`)
- **API routes** (`/api/*`): network-first, fallback to cache
- **Static assets** (`/_nuxt/*`): cache-first (hashed = immutable)
- **Everything else**: network-first with cache fallback

### 3. `composables/useOfflineDb.ts`
IndexedDB wrapper (`oasis-offline` database) with stores:
- `passes` — cached walk-in pass lookups
- `coaches` — cached coaches list
- `clients` — cached client sessions
- `reports` — cached report data (keyed by period)
- `writeQueue` — queued offline write operations
- `meta` — session cache, misc metadata

Exports: `put`, `putAll`, `get`, `getAll`, `clear`, `remove`

### 4. `composables/useOnlineStatus.ts`
Reactive `isOnline` / `wasOffline` refs using `navigator.onLine` + event listeners.

### 5. `composables/useWriteQueue.ts`
- `enqueue(entry)` — saves failed POST to IndexedDB `writeQueue`
- `sync()` — replays all queued items when online, shows toast results
- `queueLength` — reactive count of pending operations
- Auto-syncs when `isOnline` flips to `true`

### 6. `composables/useCachedFetch.ts`
Wrapper around `$fetch`:
- `cachedGet(url, { params, cache })` — fetch + cache to IndexedDB; offline returns cached
- `cachedPost(url, body, { label, cacheInvalidates })` — POST or queue if offline; clears related caches on success

### 7. `components/OfflineIndicator.vue`
Fixed bottom-right badge showing:
- Red "Offline" with pulse dot when disconnected
- "N queued" count with "Sync now" button when online + pending ops
- Green "Back online — syncing…" toast on reconnect

## Modified Files (3)

### `nuxt.config.ts`
- Add `{ rel: 'manifest', href: '/manifest.json' }` to `app.head.link`
- Add SW registration script to `app.head.script`

### `app.vue`
- Add `<OfflineIndicator />` alongside `<AppToast />`

### `pages/staff/index.vue`
Replace `$fetch` calls with cache-aware versions:
- **GET calls** (reports, coaches, clients, leaderboard, payments, lookup) → `cachedGet` with appropriate cache store
- **POST calls** (checkout, register, coach CRUD, client CRUD, payment status) → `cachedPost` with queue fallback
- **Session check** → cache auth result in IndexedDB `meta` store (trust for 8 hours when offline)
- Catch "Queued for sync" errors gracefully — show pending state, not error toast

## Implementation Order
1. `composables/useOfflineDb.ts`
2. `composables/useOnlineStatus.ts`
3. `composables/useWriteQueue.ts`
4. `composables/useCachedFetch.ts`
5. `public/manifest.json` + `public/sw.js` + `nuxt.config.ts` edits
6. `components/OfflineIndicator.vue`
7. `app.vue` — add indicator
8. `pages/staff/index.vue` — integrate cached fetch/queue

## What Stays Online-Only
- File uploads (receipts, coach photos) — queued, can't upload offline
- OCR receipt scanning — requires Gemini API
- Email sending (reminders, approval/rejection)
- Admin login (requires server session)
- Receipt signed URL generation
